\chapter{\dysta{}: Static-Dynamic Disentanglement for Efficient Multi-Frame Vision-Language-Action Models}
\label{chapter:dysta}

Chapter~\ref{chapter:mwm} used the visual consequences of behavior to learn neural representations for action-intention decoding. We now ask how machines can translate human intentions into physical action, enabling them to carry out tasks effectively and efficiently on behalf of their users. This chapter introduces \dysta{}, which addresses two obstacles to this capability: limited temporal memory and costly repeated inference. By separating persistent and changing visual information, the method supports multi-frame task reasoning and reuses computation across control steps.
